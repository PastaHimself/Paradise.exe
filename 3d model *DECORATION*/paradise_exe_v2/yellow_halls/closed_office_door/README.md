# Closed office door
16×30 units including frame; 17 cubes, separate frame/leaf groups, static closed pose.
Birch leaf, spruce frame, iron paired lever handles and narrow open vision slot (no glazing).
64×64 atlas contains unchanged whole vanilla 16×16 tiles copied at original resolution. Source paths in plan.json.
All active faces 1 px/unit, including 90° rotated wood mapping. Handle stem/lever pieces meet without overlapping bottom faces.
Source closed_office_door.bbmodel; Bedrock closed_office_door.geo.json; texture closed_office_door.png.
Original pixels and embedded/exported PNG bytes verified; front/back/three-quarter/gameplay MCP screenshots inspected.
Unique geometry naming, block bindings, opening animation and in-game tests remain for the later integration phase.
References: https://www.kriegerproducts.com/gallery/sf-conservatory/ and https://www.sheltonoffice.com.my/office-door/933-nyatoh-plywood-door.html
