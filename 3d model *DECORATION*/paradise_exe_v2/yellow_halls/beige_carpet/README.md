# Yellow Halls carpet vanilla substitutes
Base: wool_colored_white.png (off-white, closest original fiber texture to beige).
Worn path: wool_colored_silver.png. Dark patches: wool_colored_brown.png.
Every PNG is copied byte-for-byte from local samples. Whole-tile state materials, no painted spot/path overlays.
carpet_preview.bbmodel is Generic Model tiled preview only; four 16×16×1 tiles, 1 px/unit.
*_tiled_preview.png show complete 2×2 arrangement. Runtime export not applicable to texture-only files.
Local source paths in vanilla_sources.json. No in-game check.
