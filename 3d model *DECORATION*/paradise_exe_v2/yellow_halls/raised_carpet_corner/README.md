# Raised carpet corner
Three thin cuboids, 16×16 base footprint, 4×4 corner flap lifted 30°; thickness 0.125 units. 18 quads / 36 triangles.
Three original vanilla wool textures: white base/off-white beige substitute, silver worn, brown dark.
Source PNGs copied byte-for-byte; all face mappings 1 pixel/unit including the rotated flap.
Source raised_carpet_corner.bbmodel; runtime raised_carpet_corner.geo.json. Base active; three textures included.
Native MCP base/worn/dark three-quarter plus side/underside/gameplay screenshots inspected.
Stylized square flap rather than rounded cloth curl; no meshes, animation or custom texture pixels.
Unique geometry identifier and block material/state integration remain for later; no in-game test.
