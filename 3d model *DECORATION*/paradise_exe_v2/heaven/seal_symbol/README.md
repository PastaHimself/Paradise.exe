# Heaven — Seal symbol texture suite
4 texture variants copied byte-for-byte from vanilla Bedrock preview textures:
- quartz_rosette: quartz_block_chiseled.png
- blackstone_ward: chiseled_polished_blackstone.png
- chiseled_glyph: chiseled_nether_bricks.png
- tuff_medallion: chiseled_tuff_bricks.png

All 16x16 PNG files verified byte-identical.
`heaven_seal_symbol_preview.bbmodel` provides a 2x2 vertical preview wall at 1 px/unit scale with 100% full coverage.
