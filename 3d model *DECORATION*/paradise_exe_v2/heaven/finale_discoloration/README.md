# Heaven — Finale discoloration texture suite
4 texture variants copied byte-for-byte from vanilla Bedrock preview textures:
- mineral_leaching: calcite.png
- dripstone_staining: dripstone_block.png
- ash_darkening: tuff.png
- eldritch_tarnish: gilded_blackstone.png

All 16x16 PNG files verified byte-identical.
`heaven_finale_discoloration_preview.bbmodel` provides a 2x2 vertical preview wall at 1 px/unit scale with 100% full coverage.
