## Global guardrails

- Ship static blocks only. No custom placement/interact/break hooks, commands attached to props, items, inventories, entities, schedules for décor states or new level transitions. Multiple fixture states are authored choices placed by the existing generation pass. Existing gameplay stays operational and keeps its current IDs and handlers.
- Deferred items are Yellow Halls `breaker_box` and OVERLOAD / SEVER levers, `addon/BP/scripts/paradise_loop.js` (absent), Library `archive_desk`, `card_reader_terminal` and the chat/riddle, question chest and debt logic in `library.js`, Catacombs shortcut interaction/door logic, Heaven `seal_pedestal`, `seal_face`, `seal_floor_inlay`, and the interactive exit. The static Heaven architectural panel, frame and emblems and static Catacombs architectural doorway are in scope.
- Keep Overworld mistake triggers, `main.js` lifecycle wiring, `dimension_horror_rules.js` travel helpers, `destructive_horror_events.js`, `harmful_player_events.js`, `horror_events_v2.js`, `watcher_*.js`, `stalker_teleport_governor.js`, `addon/BP/entities/watcher.json`, and the Watcher client entity, models, animations and animation controllers out of this pass. No Entity 8 or new entities. Keep Catacombs timers, Staircase fall/rules, Highway chase/collapse and Heaven trust/interact/return behavior. Preserve campaign and travel property keys, schedules and ticking-area cleanup.
- XYZ intervals are inclusive and refer to **block cells**. Structure local origin is `(0,0,0)`; world placement is `origin + local cell`, without rotation unless stated. The asset tables show **model-pixel** bounds, with X/Z centered at 0 and floor Y=0. A role's anchor owns every segment cell; reject overlaps before placing. Keep a minimum two-block-wide connected walking strip with two clear occupied-player height cells and usable head clearance at stairs. Flush-mount into the owning wall / ceiling cell or the declared backed ledge. Every post, satellite segment and suspended piece touches floor, wall, ceiling or a structural support. Prefer terrain replacement at Y64 for walkable surface textures.
- Select only original vanilla pixels and copy or tile 1:1. Crop an animation frame explicitly and log its rectangle. No manual paint, repaints, resampling, tint baking, AI assets or new fonts drawn into an atlas. Use existing geometry lettering or Bedrock's native pixel font through waxed static signs. Use cutout only where alpha is present. Bake low-power contrast with lit and dark source pixels plus nearby normal light.
- `minecraft:geometry` and `minecraft:material_instances` travel together wherever either is defined. Use a numeric `ambient_occlusion: 1.0` for this project. Valid decimal range is 0–10 with 1 the default in strict 1.26.20+ block format. Tags, when needed, go in `"minecraft:tags": ["paradise:static_decor"]` as namespaced strings. Do not emit top-level `tag:...` keys. [1.26.20 creator notes](https://learn.microsoft.com/minecraft/creator/documents/update1.26.20?view=minecraft-bedrock-stable#block-components) · [Material instances](https://learn.microsoft.com/minecraft/creator/reference/content/blockreference/examples/blockcomponents/minecraftblock_material_instances?view=minecraft-bedrock-stable)
- Use `minecraft:placement_direction` with `minecraft:cardinal_direction` only for directional placement. Documented offsets are `0.0`, `90.0`, `180.0` and `270.0`. Normalize a full turn to `0.0`. Generated and structure placements set cardinal state explicitly. For north-facing source geometry use transforms N=0, E=−90, S=180, W=90, and test the authored front at each heading. A geometry row marked `C` uses cardinal orientation, while `F` uses its authored fixed axis. One state with four rotations suffices. Texture options use the discrete IDs in the placement specs or a fixed atlas. `minecraft:collision_box` supports boolean, an origin/size box and multiple min/max boxes up to Y=24 at target. Use false for supported thin plates, wires, lamps and flat trim and per-cell blocking for furniture and railings. Use the 24-unit allowance only over a guard zone. [Placement direction](https://learn.microsoft.com/minecraft/creator/reference/content/blockreference/examples/traits/placement_direction?view=minecraft-bedrock-stable) · [Collision box](https://learn.microsoft.com/minecraft/creator/reference/content/blockreference/examples/blockcomponents/minecraftblock_collision_box?view=minecraft-bedrock-stable)
- Default block light is 0. Emitting fixtures use `minecraft:light_emission` at the listed integers. Bake stair safety constraints and same-height floor transitions. Performance target is at most four permutations per directional ID, one material atlas per unit, two layers of terrain occupancy at most, and no decorator polling. Emit once in the owning job, in chunk order, with one authored root per site. Use existing queue/ticking areas. For .mcstructure preserve size/origin and committed block-entity / functional cells. Use palette `-1` for intentionally untouched cells and explicit air only for a planned carve. Guard against deferred structure placement overwriting a fresher patch.

Preserve normalized UV space unless an agreement test against the bitmap proves remapping is needed. Publish each staged shape once and reuse its runtime geometry across identical-shape palette IDs. If a rotation crosses a cell boundary, use adjoining cell-sized replacements matching the profile and source tiles.
